Evidence-backed work

Research prototype

Iterative Query Planning for Building Knowledge Graphs

Developed an auditable research prototype for answering questions across heterogeneous Brick building knowledge graphs. The system compares fixed query planning with bounded ontology refinement and observed-path inspection, using deterministic compilation and evaluation to expose both successful recoveries and the limits of iterative reasoning.

Contribution
Developed the research prototype and its evaluation workflow.
Methods
Python, Brick ontology, SPARQL, deterministic planning and compilation, and witnessed-path validation.
Learning
The prototype exposes successful recoveries alongside the limits of iterative reasoning; the current evidence does not establish general superiority.

Course team project

Histopathology Image Classification Pipeline

Co-developed a course-team pipeline for five-class colorectal histopathology image classification. My archived work covers data exploration, magnification-normalized patch generation, low-information filtering, and evaluation of a lightweight HistoGhost model using label smoothing, CutMix, and patch-level ensemble voting. This was an academic experiment, not a clinically validated system.

Contribution
My archived work covers data exploration, magnification-normalized patch generation, low-information filtering, and model evaluation.
Methods
Patch generation and filtering, lightweight model adaptation, label smoothing, CutMix, and ensemble voting.
Outcome
An end-to-end academic five-class classification pipeline; not a clinically validated system.

Group machine-learning project

Air Quality Forecasting and Anomaly Detection

Contributed to a group machine-learning workflow for multivariate air-quality data, spanning preprocessing, anomaly detection, temporal feature engineering, and chronological multi-horizon evaluation. The experiments compared persistence baselines with linear and tree-based models and showed that anomaly flags did not consistently improve predictive performance.

Contribution
Contributed across the full project lifecycle as part of the team.
Methods
Preprocessing, anomaly detection, temporal features, chronological splits, and multi-horizon evaluation.
Learning
Anomaly indicators did not consistently improve predictive performance.

Five-person course study

Fine-Grained Sentiment Analysis Across Product Domains

Co-authored a five-person NLP study comparing sparse baselines, supervised transformers, parameter-efficient language-model adaptation, and prompt-based classification for aspect-level sentiment across restaurant and laptop reviews. The analysis focused on cross-domain transfer and recurring errors involving neutral sentiment, contrast, and target-specific attribution.

Contribution
Contributed across the full project lifecycle as part of the team and co-authored the study.
Methods
Sparse baselines, supervised transformers, parameter-efficient adaptation, prompt-based classification, and qualitative error analysis.
Learning
Neutral sentiment, contrast, pragmatic reasoning, and target-specific attribution remained recurring challenges.
